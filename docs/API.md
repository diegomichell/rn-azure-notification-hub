# API reference

All exports come from the package root:

```ts
import * as AzureNotificationHub from 'rn-azure-notification-hub';
// or
import { startAsync, addTagAsync } from 'rn-azure-notification-hub';
```

Functions whose name ends in `Async` return a `Promise`. Anything that mutates the installation
throws `ERR_NOT_STARTED` until [`startAsync`](#startasync) has resolved; reads work beforehand and
return whatever the SDK has persisted from previous launches.

## Lifecycle

### `startAsync`

```ts
startAsync(config: NotificationHubConfig): Promise<void>
```

Starts the native SDK and registers the device for push notifications. On iOS this requests
notification authorization (triggering the system prompt) and calls
`registerForRemoteNotifications()`; on Android it starts the hub against the `Application` and asks
Firebase for a token.

Pass either `connectionString` + `hubName`, or `installationManagement: true`. Anything else throws.

Calling it again with the same configuration is harmless. Calling it with a *different* hub
replaces the target for subsequent upserts but does not delete the previous hub's registration —
do that from your backend.

### `isStarted`

```ts
isStarted(): boolean
```

Synchronous. Whether `startAsync` has completed in this process. Resets to `false` when the process
is killed, not when JavaScript reloads.

### `setEnabledAsync` / `isEnabledAsync`

```ts
setEnabledAsync(enabled: boolean): Promise<void>
isEnabledAsync(): Promise<boolean>
```

Disabling stops the SDK from upserting installations and makes it drop incoming notifications
rather than delivering them. The flag is persisted by the native SDKs across launches; the default
is enabled.

Note this does not unregister the device from the hub. To stop delivery server-side, clear the
installation from your backend.

## Installation

### `getInstallationAsync`

```ts
getInstallationAsync(): Promise<Installation>
```

A snapshot of the record this device is registered with, read from the SDK's local store. It can be
momentarily ahead of the hub while an upsert is in flight — [`onInstallationSaved`](#events) tells
you when the hub has actually accepted it.

### `saveInstallationAsync`

```ts
saveInstallationAsync(): Promise<void>
```

Forces an upsert now instead of waiting out the SDK's debounce window (~2s). Useful after a batch
of changes, or to retry after a reported failure.

### `getInstallationIdAsync` / `setInstallationIdAsync`

```ts
getInstallationIdAsync(): Promise<string | null>
setInstallationIdAsync(installationId: string): Promise<void>
```

The installation id is generated by the SDK on first registration. Override it when your backend
already has a stable device identifier and you want hub records keyed by it. The override is
persisted and reapplied on every subsequent upsert.

> The iOS SDK has no installation-id setter. This library applies the value through
> `MSInstallationEnrichmentDelegate`, which runs immediately before each upsert.

### `getPushChannelAsync` / `setPushChannelAsync`

```ts
getPushChannelAsync(): Promise<string | null>
setPushChannelAsync(pushChannel: string): Promise<void>
```

The APNs device token (lowercase hex) on iOS, the FCM registration token on Android. `null` until
the OS has issued one — always `null` on the iOS simulator.

`setPushChannelAsync` exists for the case where another library owns the push token; see
[Coexisting with other FCM libraries](../README.md#coexisting-with-other-fcm-libraries). On iOS it
throws `ERR_INVALID_PUSH_CHANNEL` if the string is not valid hex.

### `getUserIdAsync` / `setUserIdAsync`

```ts
getUserIdAsync(): Promise<string | null>
setUserIdAsync(userId: string | null): Promise<void>
```

Associates a user identifier with the installation so a backend can target a person across their
devices. Pass `null` to clear it, typically on sign-out alongside `clearTagsAsync()`.

### `getPlatformAsync` / `setPlatformAsync`

```ts
getPlatformAsync(): Promise<InstallationPlatform | null>
setPlatformAsync(platform: InstallationPlatform): Promise<void>
```

Always `'apns'` on iOS, and `setPlatformAsync` throws `ERR_UNSUPPORTED_ON_PLATFORM` there.

On Android the SDK reports `'fcmv1'`. Override it only for a hub still configured with the legacy
`gcm` credential.

### `setExpirationAsync`

```ts
setExpirationAsync(expiration: Date | null): Promise<void>
```

Sets when the hub should expire this installation, or `null` for never. Applied on every subsequent
upsert.

> Neither SDK exposes a setter on its public surface. This library applies the value through
> `MSInstallationEnrichmentDelegate` (iOS) and an `InstallationVisitor` (Android).

## Tags

```ts
addTagAsync(tag: string): Promise<boolean>
addTagsAsync(tags: string[]): Promise<boolean>
removeTagAsync(tag: string): Promise<boolean>
removeTagsAsync(tags: string[]): Promise<boolean>
getTagsAsync(): Promise<string[]>
clearTagsAsync(): Promise<void>
```

Each mutation returns `true` when the tag set actually changed, and schedules an upsert.
`getTagsAsync` returns them sorted.

Service limits: 120 characters per tag, no commas, 60 tags per installation.

## Templates

```ts
setTemplateAsync(name: string, template: InstallationTemplate): Promise<boolean>
removeTemplateAsync(name: string): Promise<boolean>
getTemplateAsync(name: string): Promise<InstallationTemplate | null>
getTemplatesAsync(): Promise<Record<string, InstallationTemplate>>
clearTemplatesAsync(): Promise<void>
```

`setTemplateAsync` replaces any template registered under the same name and returns `true` when the
stored templates changed.

## Custom installation management

### `completeInstallationUpsert`

```ts
completeInstallationUpsert(requestId: string, error?: string | null): void
```

Synchronous. Acknowledges an [`onInstallationUpsertRequested`](#events) event exactly once. Pass an
`error` message to report the upsert as failed — it surfaces through
`addInstallationSaveFailedListener` and the SDK retries later.

Throws `ERR_UNKNOWN_UPSERT_REQUEST` if the id is unknown, which happens when it was already
acknowledged or when it timed out.

## Permissions

```ts
getPermissionsAsync(): Promise<NotificationPermissions>
requestPermissionsAsync(options?: AuthorizationOption[]): Promise<NotificationPermissions>
```

`getPermissionsAsync` never prompts. `requestPermissionsAsync` prompts if the OS still allows it.

On Android the `options` argument is ignored; the runtime permission is `POST_NOTIFICATIONS`
(API 33+). Below API 33 the result reflects whether notifications are enabled in system settings,
with `canAskAgain: false`.

## Events

Each `add*Listener` returns an `EventSubscription`; call `.remove()` to unsubscribe.

| Function | Payload | Fires when |
| --- | --- | --- |
| `addNotificationReceivedListener` | [`NotificationPayload`](#notificationpayload) | A notification is delivered to the app. |
| `addInstallationSavedListener` | `{ installation }` | The hub (or your backend) accepted an upsert. |
| `addInstallationSaveFailedListener` | `{ installation, message, code }` | An upsert failed. |
| `addInstallationUpsertRequestListener` | `{ requestId, installation }` | `installationManagement` mode wants an installation persisted. |
| `addAuthorizationListener` | `{ granted, message }` | iOS only — the user answered the prompt `startAsync` triggered. |

Notifications that arrive before any listener is attached are buffered (up to 32, oldest dropped)
and replayed with `buffered: true`.

The module also extends Expo's `NativeModule`, so the raw event names work with `useEvent` and
`useEventListener`:

```ts
import { useEvent } from 'expo';
import { AzureNotificationHubModule } from 'rn-azure-notification-hub';

const notification = useEvent(AzureNotificationHubModule, 'onNotificationReceived');
```

| --- | --- | --- |

| `hubName` | `string?` | Required unless `installationManagement`. |
| `installationManagement` | `boolean?` | Route upserts through JavaScript. Default `false`. |
| `installationUpsertTimeout` | `number?` | ms before an unacknowledged upsert fails. Default `30000`. |
| `authorizationOptions` | `AuthorizationOption[]?` | iOS only. Default `['alert', 'sound', 'badge']`. |

## Errors

| Code | Meaning |
| --- | --- |
| `ERR_NOT_STARTED` | A mutating call ran before `startAsync()` resolved. |
| `ERR_INVALID_CONFIGURATION` | `startAsync()` got neither a connection string + hub name nor `installationManagement`. |
| `ERR_INVALID_PUSH_CHANNEL` | iOS — `setPushChannelAsync` was given something that is not a hex APNs token. |
| `ERR_UNSUPPORTED_ON_PLATFORM` | The call has no equivalent on this platform (`setPlatformAsync` on iOS). |
| `ERR_UNKNOWN_UPSERT_REQUEST` | `completeInstallationUpsert` was given an id that is not pending. |
| `ERR_FIREBASE_NOT_CONFIGURED` | Android — `startAsync()` could not get an FCM token because the default `FirebaseApp` was never initialised. Almost always a missing `google-services.json`. |
| `ERR_MISSING_APPLICATION_CONTEXT` | Android — the React context had no `Application`, which should not happen in a normal app. |

## Mapping to the native SDKs

| This library | iOS (`MSNotificationHub`) | Android (`NotificationHub`) |
| --- | --- | --- |
| `startAsync({ connectionString, hubName })` | `start(connectionString:hubName:options:)` | `start(application, hubName, connectionString)` |
| `startAsync({ installationManagement: true })` | `startWithInstallationManagement(_:options:)` | `start(application, adapter)` wrapped in `PushChannelValidationAdapter` + `DebounceInstallationAdapter` |
| `setEnabledAsync` / `isEnabledAsync` | `setEnabled:` / `isEnabled` | `setEnabled` / `isEnabled` |
| `saveInstallationAsync` | `willSaveInstallation` | `beginInstallationUpdate` |
| `getInstallationIdAsync` | `getInstallationId` | `IdAssignmentVisitor` |
| `setInstallationIdAsync` | `MSInstallationEnrichmentDelegate` | `setInstallationId` |
| `getPushChannelAsync` | `getPushChannel` | `PushChannelVisitor` |
| `setPushChannelAsync` | `didRegisterForRemoteNotificationsWithDeviceToken:` | `PushChannelVisitor.setPushChannel` |
| `get/setUserIdAsync` | `getUserId` / `setUserId:` | `getUserId` / `setUserId` |
| `get/setPlatformAsync` | n/a (always `apns`) | `PlatformVisitor` |
| `setExpirationAsync` | `MSInstallationEnrichmentDelegate` | `InstallationVisitor` |
| tags | `addTag:`, `addTags:`, `removeTag:`, `removeTags:`, `getTags`, `clearTags` | `addTag`, `addTags`, `removeTag`, `removeTags`, `getTags`, `clearTags` |
| `set/remove/getTemplateAsync` | `setTemplate:forKey:`, `removeTemplateForKey:`, `getTemplates` | `setTemplate`, `removeTemplate`, `getTemplate` |
| `getTemplatesAsync` / `clearTemplatesAsync` | `getTemplates` (+ loop) | `TemplateVisitor` |
| `onNotificationReceived` | `MSNotificationHubDelegate` | `NotificationListener` |
| `onInstallationSaved` / `onInstallationSaveFailed` | `MSInstallationLifecycleDelegate` | `setInstallationSavedListener` / `setInstallationSaveFailureListener` |
| `onInstallationUpsertRequested` | `MSInstallationManagementDelegate` | `InstallationAdapter` |
| `onAuthorizationRequested` | `notificationHub:didRequestAuthorization:error:` | n/a |
